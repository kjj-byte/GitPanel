添加 GitHub 账户

使用 OAuth 授权，或粘贴一个/多个 Token 登录。面板不会接触你的密码或浏览器 Cookie。

一次性设置：创建一个 GitHub OAuth App，并勾选 Enable Device Flow。

  1. 打开 GitHub → Settings → Developer settings → OAuth Apps → New OAuth App。
  2. Homepage URL 填 http://127.0.0.1:7788，Callback URL 可填同一地址。
  3. 创建后复制 Client ID（不是 Client Secret）。

Client ID 是公开信息，只用于发起设备授权，不会泄露账户。

如何获取 Token？

Classic PAT（推荐）

  1. 登录目标 GitHub 账户，打开 Settings → Developer settings → Personal access tokens。
  2. 选择 Tokens (classic) → Generate new token (classic)。
  3. 勾选 read:user 和 public_repo，生成后立即复制 ghp_...。
  4. 每行粘贴一个 Token；多个账户分别登录后重复以上步骤。

Fine-grained PAT：需要能读取用户信息，并具备 Star 目标仓库的权限；不确定时用 Classic PAT。登录成功只代表能读取账户，Star 仍可能因权限不足失败。

Token 等同密码，只在本机使用；批量最多 50 个，空行和重复 Token 会自动跳过。

OAuth 授权范围：read:user、public_repo。Token 登录需要至少能读取用户信息；Star 需要 public_repo 或对应仓库的 Star 权限。移除账户只删除本地令牌，不会自动撤销 GitHub 授权。
